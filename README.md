# Animated-website-with-gsap

Animated digital marketing agency website inspired by WizardZ / Positivus, built with HTML, CSS, JavaScript, and GSAP (GreenSock Animation Platform) + ScrollTrigger.

## Features
- **GSAP Timelines & Staggers**: Smooth initial entrance animations for Navbar, Hero section, and CTA buttons.
- **GSAP ScrollTrigger**: Scroll-driven directional fly-in animations for service cards from outside the screen.
- **Infinite Brand Marquee**: Smooth infinite logo carousel with hover slowdown.
- **Interactive 3D Tilt & Parallax**: Mouse tracking with dynamic 3D rotation on service cards and hero illustration.
- **Continuous Floating Animations**: Ambient idle floating on SVG illustrations.
